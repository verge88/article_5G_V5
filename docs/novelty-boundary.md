# Границы заявления о научной новизне

Эта реализация проверяет гипотезу о **применении исключения происхождения
признаков к проверке аутентифицированной отчётности NF в иерархическом
мониторинге 5G Core**. Она не устанавливает мировой приоритет и не предлагает
новый тип MLP, линейной регрессии или деревьев.

## Что уже известно

- Batson и Royer, *Noise2Self: Blind Denoising by Self-Supervision*, ICML 2019:
  восстановление при ограничении зависимости от части входа имеет известную
  теоретическую основу. Поэтому сама идея исключить проверяемую компоненту
  не может объявляться новой. Предпосылки Noise2Self о независимом шуме не
  переносятся автоматически на недостоверные отчёты NF и коррелированный трафик.
  [Первичный источник](https://proceedings.mlr.press/v97/batson19a.html).
- Manias, Chouman и Shami, *A Model Drift Detection and Adaptation Framework
  for 5G Core Networks*, MeditCom 2022: ML, изменение поведения пользователей
  и проверка на действующем прототипе 5G Core уже изучались. Наш `heldout` —
  тест переноса между процедурами, без реализации их механизма адаптации.
  [Первичный источник](https://arxiv.org/abs/2209.06852).
- Isaac, Saradagam и Pardhasaradhi, *5G Core Fault Detection and Root Cause
  Analysis using Machine Learning and Generative AI*, 2025: классификация
  нормальных и ошибочных PCAP-кадров и объяснение неисправностей средствами ML/LLM
  уже описаны. Настоящий эксперимент проверяет согласованность отчётов и
  внешних измерений; этот опубликованный FA Engine здесь не воспроизводится.
  [Первичный источник](https://arxiv.org/abs/2508.09152).
- Ganiuly, Bolatbek и Smaiyl, *Cross-Layer Detection of Wireless Misbehavior
  Using 5G RAN Telemetry and Operational Metadata*, 2025: межуровневая
  согласованность телеметрии уже используется как признак некорректного поведения.
  В той работе рассматривается RAN; наш стенд исследует SBI в ядре и добавляет
  экспериментальные КИЕ. Общая идея согласованности сама по себе не новая.
  [Первичный источник](https://arxiv.org/abs/2511.21803).

## Узкое проверяемое отличие

Вместо исключения только текущего отчёта удаляется весь набор его производных
входов: сводные признаки и история проверяемого источника. Независимость входа
от этих отчётов проверяется преобразованием данных, а полезность — отдельными
сценариями, простыми правилами, абляциями и доверительными интервалами.
КИЕ проходят по реальному SCP–NF пути и позволяют отделить подлинность источника
от правдивости содержания. Это постановка и реализованный экспериментальный
вклад; утверждение «впервые» требует дальнейшего полного обзора литературы.

Даже положительный основной результат означает лишь поддержку конкретной
гипотезы на данном стенде. Если исключение источника не превосходит базовые
методы или повышает FPR, результаты не дают основания заявлять улучшение
обнаружения. Эксперимент и отрицательный результат сохраняются без подбора
новой основной гипотезы задним числом.
